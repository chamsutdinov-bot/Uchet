Настройка входа в приложение

Эта страница работает только в вашем браузере, ничего никуда не отправляет. Она превращает ключ GitHub в зашифрованный файл access.json, который открывается вашим паролем.

  1. В репозитории uchet нажмите Add file → Create new file.
  2. Имя файла: access.json
  3. Вставьте скопированный текст и нажмите Commit changes.
